# Contributing

Project Symphony welcomes constructive discussion, experimentation, and
thoughtful collaboration.

## Contribution Scope

Encouraged:

- public research notes
- conceptual diagrams
- workflow observations
- terminology improvements
- discussion of human-AI collaboration patterns
- public demonstrations that do not expose private implementation details

Not accepted:

- private research notes
- credentials
- personal data
- proprietary implementation details
- private routing or orchestration methods
- generated private logs or workspace artifacts

## Collaboration Standard

Project Symphony values curiosity, respectful debate, and a willingness to
explore new approaches to human-AI collaboration.
