# Security And Privacy

Do not disclose credentials, personal data, private research, or proprietary
implementation details through public issues, pull requests, discussions, or
commits.

## Public Boundary

This repository may discuss public concepts, research themes, and collaboration
models.

It must not include:

- credentials or tokens
- personal data
- private workspace artifacts
- private research notes
- proprietary routing logic
- unreleased runtime internals
- generated private logs

## Reporting A Concern

Report the affected path and commit reference without copying private content
into the report.
