# Collaboration Model

Project Symphony treats AI as a coordinated support system rather than a single
isolated assistant.

## Core Pattern

```text
Human intent
  -> shared context
  -> specialized assistance
  -> coordinated output
  -> human review
  -> continued collaboration
```

## Responsibilities

The human provides:

- direction
- standards
- taste
- approval
- final judgment

AI systems provide:

- options
- drafts
- checks
- synthesis
- execution support
- critique

## Principle

Coordination should make work easier to understand, not harder.

If orchestration adds confusion, it has failed its purpose.
